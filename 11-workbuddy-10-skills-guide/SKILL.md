# WorkBuddy 10 个实用 Skill 清单与安装指南

来源（飞书，千雪整理 2026.08）：https://ccnope4jr4h4.feishu.cn/docx/Zd6ydP1eaoeTk1xZeOOcE5M6nl0

## 先看结论：这 10 个 Skill 怎么组合
最有效的用法不是把技能库塞满，而是形成一条完整链路：先找到能力，再把需求想清楚，最后交付文件、设计和视频。

| 环节 | 推荐 Skill | 主要价值 |
|------|------------|----------|
| 发现能力 | Find Skills | 从任务出发，快速定位候选技能 |
| 沉淀方法 | Skill Creator | 把高频流程封装成可复用能力 |
| 明确方案 | Brainstorming | 先比较路线与限制，再开始执行 |
| 完成交付 | PDF / PPTX / DOCX / XLSX | 把结果落实为正式文档 |
| 完成交付 | Frontend / Canvas / Remotion | 把结果落实为设计作品和成片视频 |

## 建议安装顺序
Find Skills → Brainstorming → 你最常用的交付技能 → Skill Creator。
先解决高频真实任务，再把已经跑通的流程封装起来。不要一口气安装几十个；安装数量并不等于工作效率。
