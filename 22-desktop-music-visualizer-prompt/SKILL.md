# 桌面屏保音乐律动编程提示词

来源（飞书）：https://ccnope4jr4h4.feishu.cn/wiki/N17fws434iXHpLk13BecX383nzl

## 片头演示提示词（可直接使用）
```
你是一名资深 Windows 桌面开发、WebGL、Three.js、GLSL Shader、Web Audio API 和动态壁纸开发专家。
请根据我提供的参考视频，完整制作一个 Windows 3D 音乐律动桌面壁纸程序。不要只提供代码片段或单个 HTML，必须实际创建、编译、运行、验证程序，并在桌面创建快捷方式。

【参考资料】
请先完整读取参考视频。允许使用 FFmpeg、OpenCV 或其他本地工具进行抽帧、运动分析和音频频谱分析。
至少分析以下内容：
1. 摄像机角度、透视关系、构图、地平线位置。
2. 柱体密度、尺寸、间距、可见区域和整体形状。
3. 波纹传播速度、宽度、寿命、发光强度。
4. 波源出现的位置与时间。
5. 低频、鼓点与画面波峰之间的延迟关系。
6. 暗部、中间色、波峰白光的颜色映射。
7. Bloom、曝光、景深或倾斜模糊强度。
8. 参考视频中“不规律”的真正形成机制。

不要凭印象制作。如果无法读取视频，应明确报告实际错误，并按正常权限流程申请读取该文件所需的权限。
```
