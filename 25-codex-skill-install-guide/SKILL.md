# Codex 的 Skill 安装地址及方法文档

来源（飞书）：https://ccnope4jr4h4.feishu.cn/wiki/Zr2xw9u4Ei6FYpkbRJ8cT0VKn1c

## Skill 下载地址（来自文档）
1. **Skill Creator**
   https://github.com/anthropics/skills/blob/main/skills/skill-creator/SKILL.md
2. **Any Search**
   https://github.com/anysearch-ai/anysearch-skill
3. **Superpowers**
   https://github.com/obra/Superpowers

## 安装方法
**1、通过命令行工具安装**
在命令行工具打开 Codex 后，输入命令（地址改成对应的 skill 地址）：
```
$skill-installer install https://github.com/anysearch-ai/anysearch-skill
```

**2、直接通过 Codex 对话框安装**
直接张贴对应的 skill 地址到 Codex 的对话框，输入提示词：
> 帮我安装这个 skill。

## 在 WorkBuddy 中的使用方式
WorkBuddy 自带技能创建能力（skill-creator），一般无需通过上述 Codex 专用地址安装；如需这些社区技能，请在能联网（GitHub 可访问）的机器上克隆后，把技能目录放入对应工具的 skills 目录。
