# 灵感自动入库（功能一配置说明）

> 目标：手机 Obsidian `选题灵感库/0-随手录入.md` 攒的灵感/链接，由每天 9:00 的定时任务自动解析成选题卡，写入本目录。
> 状态流转：💡 灵感 → 🟡 可评估 → 🟠 已立项 → 🟢 已排期 → 🎬 脚本草稿 → 🎥 拍摄中 → ✂ 剪辑中 → ✅ 已发布

## 一、白天怎么记（手机上，尽量省事）

- 手机打开 Obsidian → 进入 `选题灵感库/0-随手录入.md`（在 Obsidian 启动器里把它标为星标，一键直达）
- 刷到想拍的内容，**直接把链接粘进来**，可以补一句"为什么想拍"；或者直接口述一段（语音转文字粘过来）；一条一行，不用整理格式
- 示例：
  ```
  https://v.douyin.com/xxxx 这条"日历复盘"角度想拍
  口述: 看到一个博主讲 ai 字幕, 我想做一个对比测评
  口述: 旅行行程做成小程序, 教程形式分享, 想 9 月 20 日发
  ```
- **想直接排期就带上发布日期**：在灵感行里写上发布日期（`📅 2026-09-20` 或 `9月20日` 或 `09/20` 都行），agent 入库时会跳过选题池，直接倒排档期 + 归档到「📦 已排期」。不带日期就走常规流程（进选题池，等手动写日期）。
- iCloud 自动同步到 Mac，排期任务读得到。

## 二、每天 9:00 定时入库（launchd 触发）

- 入口文件：`选题灵感库/0-随手录入.md`
- **扫描范围**：整个文件中**所有 `- [ ]` 未勾选的行**（`- [x]` 已勾选的视为"已处理"，跳过）。空行（只有 `- [ ]` 符号，无文字内容）跳过不处理。
- **解析流程**：把每条 `- [ ]` 行的内容解析成一张标准选题卡，写入 `选题灵感库/` 目录：
  - 文件名：`YYYY-MM-DD 关键词.md`（用当天日期）
  - 按 `模板/选题灵感卡.md` 的字段生成：状态固定 `💡 灵感`；分类从模板给的 5 类里选；来源 = 原链接（口述无链接就写"随手录入口述转写"）；「一句话灵感」= 用户补的那句，没补就根据内容概括；「想到的钩子/切入角度」给出建议值；评分先填 0
  - **每张卡必须带上原始口述**：把 `0-随手录入.md` 里该条灵感**对应的原文逐字**复制进卡片的「## 🎙 原始口述」区块。链接条目就贴那一行的链接 + 备注；纯口述条目就整段贴转写原文。不改写、不缩写、不修口误——这一段是留给用户双击卡片时看"当初自己原话"的。
  - 同一链接如果库里已有卡片，跳过不重复建；口述条目若内容和已有卡是同一件事，也跳过并在汇报里点名说明（不要默默丢，可能只是换了种说法）
- **带发布日期的灵感 = 直接排期**：如果某条灵感行里能识别出明确的发布日期（形如 `📅 2026-09-20`、`2026-09-20`、`9月20日`、`09/20` 等），则**跳过「选题池」的手动决策，直接排期**：
  1. 选题卡状态写 `🟢 已排期`，发布日期记进卡片「后续动作」
  2. 立即按 `时间管理/_早间排期指令.md` 的倒排期规则，倒推 写脚本/拍摄·素材整理/剪辑/发布 各环节日期（判断拍摄还是素材整理、剪辑几天，按 `_早间排期指令.md` 第一节第 4 点约定，卡上未标注则按内容判断，默认拍摄）
  3. 生成全部排期产物：3 份环节笔记（`环节档案/`）+ 4 个日历事件（`内容日历/流程日历/`）+ 4 条每日小记任务（`每日小记/`）+ 看板 4 张分卡
  4. 选题卡（原卡）直接勾选 `[x]` 放入看板「📦 已排期」列（不放进「📥 选题池」）
  5. 原灵感行仍按下方「处理完后」规则标记已处理
- **入库看板**（无日期的卡，生成选题卡后立即做）：每张新卡**自动推入看板「📥 选题池」列**，格式固定：
  - `- [ ] [[{选题卡文件名}]] · 📅 ____`
  - 在 `时间管理/3-内容流程看板.md` 的 `## 📥 选题池` 段末尾追加一行（标题以 `【示例 · 可删】` 开头的卡不推）
  - `📅 ____` 是**日期占位符**，用户决定排期时把 `____` 改成发布日期（如 `📅 2026-09-15`），agent 每天 9:05 识别这个日期自动倒排期；不写日期 = 还没排期打算，卡留在选题池
  - 已有同名行（选题卡名相同）→ 跳过不重复推
- **处理完后**（关键逻辑）：**不要删除原行、不要移动位置**：
  1. 把原行的 `- [ ]` 改为 `- [x]`（vault 需配 CSS 去掉勾选后的删除线，见部署 Step 3）
  2. 在原行**正下方**插入一行注释 `> ✅ 已处理 YYYY-MM-DD HH:MM → [[选题卡文件名]]`
  3. 保留原行在原地（用户能看到"这条录了什么 + 什么时候被处理 + 变成哪个卡"）
  4. 下次跑任务时 `- [x]` 行自动跳过，不会重复处理
- **汇报**：本次新增了几张卡、分别是什么、各带了哪段原始口述；推入看板「📥 选题池」几行；跳过了哪些（链接判重/口述判重/看板已有同名行）

## 三、验证

- 处理完后检查 `选题灵感库/` 是否有新卡
- 双击任意一张新卡：应能看到「🎙 原始口述」区，里面是当初在 `0-随手录入.md` 里口述/粘贴的原文，逐字保留
- `0-随手录入.md` 里处理过的行已打勾，下方带 `> ✅ 已处理` 注释
