# 自动排期（功能二 · Obsidian 内实现）

> 目标：用户在看板里决定"做哪条 + 哪天发"，9:05 自动任务读取信号 → 按环节耗时**倒排** 写脚本/拍摄·素材整理/剪辑/发布 → 写进 Obsidian（每日小记 + 内容日历）。排期结果由独立脚本 `wb-sync-ical.py`（每天 9:10 跑）单向同步到苹果系统日历，事件备注附 obsidian:// 链接。本指令**不在排期环节直接写苹果日历**。
> 状态流转：💡 灵感 → 🟡 可评估 → 🟠 已立项 → 🟢 已排期 → 🎬 脚本草稿 → 🎥 拍摄中 → ✂ 剪辑中 → ✅ 已发布

## 一、用户怎么操作（Obsidian 看板）

1. 打开 `时间管理/3-内容流程看板.md`（Kanban 视图）。
2. 在「📥 选题池」里决定要做哪条，**直接在卡上写发布日期**：卡片编辑状态下加 `📅 2026-09-10`（格式 YYYY-MM-DD）。没写日期 → 该卡停留在选题池，不会被自动排。
3. **写日期 = 决定排期**，9:05 自动任务读到带日期的卡就倒排期，排完原卡归档到「📦 已排期」。
4. **告诉 agent 这条用什么形式做**（可写在卡上，不写就按默认判断）：
   - 真人出镜 / 实拍 → 环节用「拍摄」；
   - 纯拆解 / 口播不露脸 / 录屏 / 网络素材混剪 → 环节用「素材整理」（**拍摄和素材整理二选一，永远不会同时出现**）；
   - 成片复杂、剪辑要 2 天 → 卡上写 `剪辑:2天`，不写默认 1 天。
5. 之后**不需手动拖动**——每天做完对应环节，去 `每日小记/YYYY-MM-DD.md` 勾掉对应 `#task`（任务行尾带 `→ [[环节档案/...]]` 跳转链接）。21:00 自动任务扫勾选状态，双写同步：①把 `内容日历/流程日历/` 对应事件笔记的 `complete: false → true`；②把看板对应卡片移到「✅ 已完成」列。

## 二、每天 9:05 自动排期任务指令

读取 `时间管理/3-内容流程看板.md`，找出「📥 选题池」列里**写了发布日期**的所有卡片，逐张处理：

0. **跳过示例**：标题以 `【示例 · 可删】` 开头的卡片一律忽略，不排期、不移动。
1. **读发布日期**：卡片上形如 `2026-09-10` 或 `📅 2026-09-10` 的日期即为发布日 P。没有日期 → 留在选题池，跳过不处理。
2. **判断环节序列**：
   - 第二个环节是「拍摄」还是「素材整理」，看第一节第 4 点的约定（卡片标注优先，否则按内容判断，默认拍摄）；
   - 剪辑天数：卡片写 `剪辑:2天` → 2 天；成片明显复杂（长成片/多素材/重特效）→ 2 天；其余默认 1 天。
3. **按耗时倒排**（每个环节单独占一整天，环节之间前后衔接不重叠，每天最多一个环节；最早环节在 `今天+1` 之前就开始的 → 不写，加入汇报"冲突"清单）：
   - **剪辑 1 天**：写脚本 P-3 → 拍摄/素材整理 P-2 → 剪辑 P-1 → 发布 P
   - **剪辑 2 天**：写脚本 P-4 → 拍摄/素材整理 P-3 → 剪辑 P-2、P-1 → 发布 P
4. **写入每日小记**：把各环节分别写成任务，追加到对应日期 `每日小记/YYYY-MM-DD.md` 末尾（文件不存在就创建，按 `模板/每日小记.md` 的骨架生成），每行格式：
   `- [ ] #task 内容 ·{卡片标题}-{写脚本/拍摄/素材整理/剪辑/发布} ⏳ YYYY-MM-DD HH:MM → [[环节档案/{环节笔记文件名}]]`
   - 剪辑占 2 天时，两天各写一条，日期不同；
   - 若某天已有任务，把时间错开、不重叠；
   - 写脚本那天的任务行尾可标预计时长，如 `（预计 3-5h）`，仅提示作用；
   - 发布环节任务行末尾**不挂链接**（发布不需要单独笔记）。
4.5 **生成环节笔记文件**：为每个非发布环节新建一份独立笔记到 `环节档案/` 目录：
   - **文件名**：`YYYY-MM-DD-{选题关键词(短)}-{环节}.md`（用环节对应日期 + 选题关键词 + 环节名），例：`2026-09-07-obsidian 时间管理-写脚本.md`；
   - **格式（精简版，只生成 3 块）**：
     - **frontmatter**：`日期`(环节对应日期) / `星期` / `环节`(写脚本/拍摄/素材整理/剪辑) / `选题卡`(填 `[[选题灵感库/{原选题卡文件名}]]`) / `标签`: [内容生产] / `预计用时`(写脚本 3-5h；拍摄/素材整理 2-8h；剪辑 1-2 天 8h/天)
     - **正文**：单行 `> 💡 **一句话灵感:** {选题卡「一句话灵感」段原文}` + 空行 + `⏱ 预计用时 ...` + `## 🎬 镜头分镜表`（4 列：画面展示/口播文案/镜头时长/镜头描述，预留 5 行空表给用户填；表格下方必须带提示行：`> 💡 「画面展示」格可直接粘贴图片（自动存到 附件/），控制大小在文件名后加 \|100`）+ `## 🔗 关联`（上游 1 条 + 下游 1 条 + 选题 1 条）+ `## ✅ 完成确认`（写脚本 3 条：大纲定稿/逐字稿完成/自读一遍无口误；拍摄 4 条：主镜头/备用镜头/素材导入/关键片段标记；剪辑 5 条：时间线/字幕/音频/封面/标题）
     - **不要替用户写创意内容**：分镜表等段落留空，用户当天打开笔记手填。`一句话灵感` 从选题卡复制，不另写。
   - **附件规则**：vault 已设 `attachmentFolderPath: "附件"`，用户在分镜表粘贴的图片自动存到 vault 根目录 `附件/`，不要改动该配置。
4.6 **挂链到选题卡**：打开原选题卡 `选题灵感库/{原选题卡文件名}.md`，在「后续动作」小节**下方**追加 `## 📂 环节档案` 小节，列出全部环节笔记链接。已有同名小节则**整段覆盖刷新**，不叠加。
4.7 **生成日历事件笔记**：每个环节（含发布）在 `内容日历/流程日历/` 目录**新建一个事件笔记**，文件名 `YYYY-MM-DD {选题关键词}-{环节}.md`，frontmatter 固定格式：
   ```
   ---
   title: {emoji}{环节} · {选题关键词}
   date: YYYY-MM-DD
   startTime: HH:MM
   endTime: HH:MM
   complete: false
   ---
   → [[环节档案/{环节笔记文件名}]]
   ```
   - emoji：写脚本 📝 / 拍摄 🎬 / 素材整理 🎬 / 剪辑 ✂ / 发布 🚀；发布环节正文只有 frontmatter，无链接行；
   - endTime 按默认时长写：写脚本 10:00→15:00，拍摄/素材整理 09:30→16:30，剪辑 09:00→17:00，发布 18:00→18:30；
   - 同名文件已存在 → 跳过不重复建。
5. **本环节不直接写苹果日历**：排期只落在 Obsidian。苹果日历由 `wb-sync-ical.py`（每天 9:10）单向同步，不要重复建苹果日历事件。
6. **生成看板分卡**（关键）：每个排好的选题在看板里生成 4 张独立的 `- [ ]` 行，分别落在 4 个流程列，每张一行、单行不换行（标题以 `【示例 · 可删】` 开头的卡不生成）：
   - **📝 写脚本 列**：`- [ ] 写脚本 · {选题关键词} · {MM-DD}({星期}) → [[环节档案/{YYYY-MM-DD}-{关键词}-写脚本]]`
   - **🎬 拍摄 列**：拍摄型写「拍摄」，素材整理型写「素材整理」（素材整理型也统一走 🎬 拍摄列，不单设列）
   - **✂ 剪辑 列**：剪辑 1 天 → 1 行；剪辑 2 天 → 2 行（每天 1 行，日期不同）
   - **🚀 待发布 列**：`- [ ] 发布 · {关键词} · {MM-DD}({星期}) {HH:MM}`（默认 18:00；卡上指定时间则用卡上时间）
   - 每行必须保持单个 `- [ ]` 列表项、无换行；同列已有同名行（关键词相同）→ 跳过不重复追加
   - 选题关键词 = 选题卡文件名主体去掉日期前缀，例：`2026-09-04 古诗旧物.md` → 关键词 = `古诗旧物`
6.5 **排期完成后归档原卡**：该选题的 4 张分卡已落到流程列后，把「📥 选题池」列里那张原卡（含 `📅` 日期的行）**勾选 `[x]` 并移到「📦 已排期」列**（不删除，保留排期记录）。判断依据：该关键词已在「📝 写脚本」列出现同名分卡行 → 说明已排过期，跳过。
7. **每晚同步完成状态**（21:00 任务，双写）：扫 `每日小记/` 里所有「内容 · 」任务行（形如 `- [x] #task 内容 ·xxx-写脚本 ...`），找出已勾选 `[x]` 的，每条对应一处改动：
   - **改日历事件 frontmatter**：找到 `内容日历/流程日历/{YYYY-MM-DD xxx-环节}.md`，把 `complete: false` 改成 `complete: true`
   - **改看板 markdown**：找到 `时间管理/3-内容流程看板.md` 对应卡片行（关键词 + 环节名匹配），从所在列删掉；如果是「发布」环节 → 直接删；如果是其它环节 → 移到「✅ 已完成」列
   - 已勾选的卡片行不处理（已经是完成的）
8. **汇报**：为哪几张选题排了期（标题 + 发布日 + 用拍摄还是素材整理 + 各环节日期）；新建了哪些环节笔记；新建了哪些看板分卡；新建/更新了哪些日历事件；缺发布日期/排期冲突/过发布日未发布的选题分别列出来。

## 三、环节耗时与默认节奏（想改直接改这里，agent 每次重新读本文件）

| 环节 | 占用 | 每日工作时长 | 默认开始时间 | 备注 |
|---|---|---|---|---|
| 写脚本 | 1 天 | 3-5h | 10:00 | 无 |
| 拍摄 | 1 天 | 2-8h | 09:30 | 与素材整理二选一 |
| 素材整理 | 1 天 | 2-8h | 09:30 | 与拍摄二选一 |
| 剪辑 | 1-2 天 | 8h/天 | 09:00 | 默认 1 天；复杂成片或卡片写 `剪辑:2天` → 2 天 |
| 发布 | 0 天（发 P 当天） | 即时 | 18:00 | 所有流程结束后的当天发布 |

- 想留缓冲：在卡上把发布日期提前，或在卡上写 `缓冲+N`，agent 把最早环节整体再提前 N 天。
- 判断素材整理型的常见信号：视频不需要真人出镜（拆解、教程录屏、混剪、图文转视频）。判不了默认「拍摄」。

## 四、验证

- 打开当天及未来几天的 `每日小记/`：应看到 `#task` 任务行；
- 看板里该卡已归档，「📝 写脚本」列出现分卡；
- 点开 Full Calendar：周视图里应看到每个环节的事件块；
- 打开苹果系统日历 App：「{{CAL_NAME}}」里应出现同名事件，点开事件备注里带 obsidian:// 链接（由 `wb-sync-ical.py` 每天 9:10 同步）。
