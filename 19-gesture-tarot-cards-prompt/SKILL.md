# 手势卡牌完整提示词（手势交互塔罗牌 + AR 后期）

来源（飞书）：https://ccnope4jr4h4.feishu.cn/wiki/YChGw2Tk1iqZNRktAjJcimPInGb

## 文档结构
两部分配合使用：先用第一部分做出可玩的网页游戏并录屏表演，再用第二部分把录好的视频合成出 AR 效果。

### 第一部分 · 电脑网页端手势交互塔罗牌（游戏本体）
用法：把每一步提示词按顺序粘贴给 AI（Claude / Cursor 等），每步在浏览器里跑通后再发下一步。全部代码写在一个 HTML 文件里（HTML/CSS/JS 放一起），不依赖构建工具，双击即可用 Chrome 打开。

**第 1 步 · 界面与 22 张塔罗牌数据**
```
请做一个塔罗牌抽牌网页小游戏，所有代码写在一个 HTML 文件里，不用任何构建工具。本步只做界面和数据：
1. 氛围：纯黑神秘背景，标题用优雅衬线字体写「塔罗占卜」。
2. 屏幕中间横向摆几张背面朝上的塔罗牌，牌背用深色底 + 金色花纹的 CSS 画出来（不用图片），有轻微呼吸发光。
3. JS 里内置 22 张大阿卡纳（韦特塔罗 Rider-Waite）的数据数组，每张含：编号、英文名、中文名、正位关键词、逆位关键词。牌面图片用公有领域的韦特塔罗图片链接。
4. 进入页面先显示开始界面：标题 + 一句引导语 +「开始占卜」按钮。
5. 左上角预留「切换控制方式」「全屏」按钮，右上角预留「洗牌」按钮，先不实现功能。
整体黑 + 金 + 一点紫，有仪式感。
```

**第 2 步 · 鼠标版抽牌流程（先跑通核心玩法）**
```
先用鼠标实现完整抽牌流程（手势后面再加）：
1. 点「开始占卜」进入抽牌界面，22 张大阿卡纳洗牌后作为暗牌池。
2. 鼠标悬停在牌上时牌上浮 + 发光，点击即选中。
3. 选中后播放翻牌动画，牌放大到屏幕中央，显示：韦特塔罗牌面大图、中文牌名（大字）、下方一行关键词。
4. 每张牌 50% 概率逆位：逆位时牌面旋转 180°，牌名后加「（逆位）」，用逆位关键词。
5. 看完点击收起，牌进入记录，桌上补牌，可继续抽。
6. 图片加载失败要有 onerror 兜底（显示带牌名的样式化占位牌，不要破图）。
```

**第 3 步 · 粒子特效**
加 canvas 粒子层：平时有稀疏星尘缓缓飘浮；选中牌的瞬间从牌位置爆发几百颗金白粒子向四周飘散；
