# 高端个人作品集网站提示词和流程文档

**CODEX SITES / 一页速查｜提示词与制作流程｜中文招聘作品集｜可直接复制使用**

面向招聘方的中文个人作品集网站：高端编辑设计风格（深色背景、微软雅黑、克制的米白与珊瑚红、大标题、非对称网格、大量留白），第一屏只放职业定位 + 两行价值主张 + 查看作品按钮 + 一张最强设计图。

## 01 · 可直接复制的主提示词

```
请使用 Codex Sites，为我制作一个面向招聘方的中文个人作品集网站。网站包含首页、项目经历、设计作品、视频作品、个人介绍和联系方式。第一屏只保留职业定位、两行价值主张、查看作品按钮和一张最强设计图，避免模板化介绍。整体采用高端编辑设计风格：深色背景、微软雅黑、克制的米白与珊瑚红、大标题、非对称网格和大量留白；不要渐变色、玻璃卡片和模板化图标。设计作品只展示质量最好的图片并支持全屏查看；6 个视频横向单排、静音自动循环播放，统一加低透明度暗色滤镜，加入轻微景深、视差、粒子、扫描线、进度与悬停反馈。动画短而轻，同时兼顾手机端、加载速度和无障碍。请先生成完整首版，后续只根据我的局部批注修改对应区域。最后检查导航、按钮、图片、视频、桌面端和手机端布局；先提供本地预览，确认后再部署，并核验外部访问权限。
```

## 02 · 六步制作流程

| # | 步骤 | 做法 |
|---|---|---|
| 01 | 整理素材 | 准备个人介绍、职业方向；每个项目写清背景、职责、问题与成果。图片按「项目名+序号」命名，视频先压缩。 |
| 02 | 创建首版 | 新建空白项目，把简历、图片和视频放入项目目录，明确要求使用 Sites，然后发送主提示词。 |
| 03 | 五秒检查 | 先看面试官能否在 5 秒内知道你是谁、应聘什么岗位、最值得看的内容是什么；不通过就先改层级。 |
| 04 | 统一审美 | 统一字号、间距、图片比例和运动节奏；删掉弱作品，避免所有卡片等大等宽，保留清晰留白。 |
| 05 | 加入交互 | 图片支持全屏，项目详情可展开；视频静音循环。悬停、视差、滚动和页面转场要短、轻、克制。 |
| 06 | 检查交付 | 测试电脑和手机布局、导航、按钮与视频；优化尺寸和延迟加载。部署后再用外部网络核验公开访问。 |

## 03 · 四条常用追加提示词

**1. 首页层级**
> 删除首屏大号姓名，品牌名只保留在导航栏；两行价值主张作为视觉中心。保留当前结构，只调整字号、留白与对齐。

**2. 审美统一**
> 建立统一的字号、间距、图片比例和动效规则；删除不好看的作品图，重新排列所有视觉不对称或留白失衡的区域。

**3. 视频区域**
> 删除原来的 3 个项目卡，换成 6 个本地视频并保持单排；静音、自动、循环播放，加入暗色滤镜、悬停提亮和进度反馈。

**4. 最终检查**
> 检查桌面端和手机端布局、导航、按钮、图片全屏与视频播放；优化图片尺寸和延迟加载，并提供可访问的本地或公开地址。

## 使用要点

- **顺序**：先发主提示词生成完整首版 → 五秒检查不过就改层级 → 再逐条发追加提示词精修
- **追加提示词是局部指令**：每次只针对一个区域（首页层级/审美/视频/交付），主提示词里的风格约束持续有效
- **视频规格**：6 个、横向单排、静音自动循环、低透明度暗色滤镜 + 进度/悬停反馈
- **设计禁区**：渐变色、玻璃卡片、模板化图标、等大等宽卡片墙
- **移动端与性能**：动画短而轻、图片尺寸优化、延迟加载、无障碍
- **交付**：先本地预览，确认后部署，最后用外部网络核验访问权限
