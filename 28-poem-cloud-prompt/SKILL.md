# 诗云提示词

来源（飞书）：https://ccnope4jr4h4.feishu.cn/wiki/HXsTwHzOVigNe0kW6SGc14PLnuh

## 提示词原文（可直接使用）
```
帮我做一个网页，里面有中国全历史上所有的诗人，以及他们所有的诗，每位诗人是一颗星星，他们的诗是关联诗人的一颗更小的星星，一首诗也是一颗星，都有各自的坐标，然后诗人之间根据年代、关系网络会有连接，3000年的诗都在这个宇宙里，每个都有自己的坐标，诗人的影响力越大，就越亮，帮我做出这个璀璨的宇宙世界
```

## 在 WorkBuddy 中的使用方式
可直接把上述提示词发给 WorkBuddy，让其生成一个单页/多页的沉浸式星空网页：诗人为主星、诗作为卫星，按年代与关系网络连线，影响力映射亮度。建议先用生图/设计稿定视觉基调，再进入编码。
