# Obsidian 安装 + 扩展坞配置教程（粉丝版）

跟着这份教程走完，你就能拥有一个自己的本地知识库，并能在刷网页时一键把有用内容收进去。零基础也能看懂。

Obsidian 是一款免费、私密、本地存储的笔记软件，所有笔记都是 markdown 文件，存在你自己的电脑上，不上云、不收费、不锁数据。

## 第一部分：下载安装 Obsidian

### 1.1 访问官网下载页

打开浏览器，访问 https://obsidian.md/download

### 1.2 选择你的设备版本

**Windows 用户**：
1. 在页面找到 Windows 区域
2. 点击「Universal」下载安装文件
3. 双击下载的安装文件，按提示完成安装

**macOS 用户**：
1. 在页面找到 macOS 区域
2. 点击「Universal」下载安装文件
3. 打开下载的 dmg 文件
4. 在弹出的窗口中，将 Obsidian 图标拖入 Applications 文件夹
5. 在启动台或 Applications 中打开 Obsidian

**Linux 用户**：支持 Snap / AppImage / Flatpak 三种方式，选你常用的即可。

**手机用户**：
- iOS：在 App Store 搜索「Obsidian」下载
- 安卓：在 Play Store 搜索「Obsidian」下载，或从官网下载 APK

### 1.3 首次打开 Obsidian

安装完成后，打开 Obsidian，会看到欢迎界面，提示你添加一个 vault。继续看第二部分。

## 第二部分：创建你的第一个 Vault（知识库）

Vault 就是你的知识库，本质上是你电脑上的一个普通文件夹，所有笔记都存在里面。

### 2.1 新建空 vault（推荐新手）

1. 在欢迎界面，找到「Create new vault」
2. 点击右侧的「Create」按钮
3. 在「Vault name」处输入名字（建议英文或简短中文，例如 `MyBrain`）
4. 点击「Browse」选择存放位置
   - 建议选一个稳定的位置，不要放在系统盘根目录
   - 不要放在会自动同步的网盘文件夹里（避免冲突）
5. 点击「Create」创建

### 2.2 用已有文件夹作为 vault（进阶）

如果你已经有一个文件夹想作为 vault：
1. 找到「Open folder as vault」
2. 点击「Open」
3. 选择你的文件夹
4. 点击「Open」

### 2.3 vault 创建完成后

进入 Obsidian 主界面，左侧是文件列表，中间是编辑区，右侧是反向链接等面板。到这里，你的本地知识库就建好了，可以开始写第一篇笔记试试。

## 第三部分：安装 Obsidian Web Clipper（网页收录扩展坞）

这是整个流程里最重要的一步。Web Clipper 是 Obsidian 官方推出的浏览器扩展，装上之后，你在任何网页点一下就能把内容自动转成 markdown 笔记收录进 Obsidian，视频图片直接展示，YouTube 视频自动提取字幕，网页大纲自动总结标题和内容。

### 3.1 前置准备

确保你已经：
1. 安装好 Chrome 浏览器（或任何基于 Chromium 的浏览器，如 Edge、Brave 等）
2. 注册好一个 Obsidian 账号（免费注册：https://obsidian.md/signup）

### 3.2 安装扩展

**方法 A：从 Chrome 应用商店安装（推荐）**
1. 打开 Chrome 浏览器
2. 访问 Chrome 应用商店：https://chromewebstore.google.com/
3. 在搜索框输入「Obsidian Web Clipper」
4. 找到 Obsidian 官方出品的扩展
5. 点击「添加到 Chrome」
6. 在弹出的确认框中点击「添加扩展程序」
7. 安装完成后，浏览器右上角工具栏会出现 Obsidian 图标

**方法 B：从 Obsidian 官网安装**
1. 访问 https://obsidian.md/clipper
2. 点击页面上的「Get it for Chrome」按钮
3. 跳转到 Chrome 应用商店后按方法 A 步骤 5-7 操作

### 3.3 登录并绑定 vault

1. 点击浏览器右上角的 Obsidian 图标，打开扩展面板
2. 首次使用会提示登录，输入你的 Obsidian 账号密码登录
3. 登录后，扩展会自动检测到你本地的 vault
4. 选择你要默认保存到的 vault
5. 可以设置默认保存的文件夹（建议新建一个叫 `Clippings` 的文件夹专门存放网页收录）

### 3.4 配置收录模板（可选但推荐）

扩展支持自定义模板，建议配置一下让收录内容更有结构：
1. 点击扩展面板右上角的设置图标
2. 进入「Templates」
3. 可以设置：
   - 自动提取标题作为笔记名
   - 自动总结网页大纲
   - 自动添加标签（如 `#clippings`）
   - 自动添加来源链接
4. 保存模板

### 3.5 实际使用演示

装好之后，下次你刷到有用的内容：
1. 在网页上点击浏览器右上角的 Obsidian 图标（或用快捷键，默认 `Ctrl+Shift+O` / `Cmd+Shift+O`）
2. 弹出收录面板，显示自动提取的标题、内容摘要
3. 确认保存位置和模板
4. 点击「Save to Obsidian」
5. 内容会自动转成 markdown 笔记，进入你指定的 vault 文件夹
6. 视频和图片会直接展示在笔记里
7. YouTube 视频会自动提取字幕内容

整个过程一秒搞定，再也不用手动截图、复制粘贴、整理收藏夹。

## 第四部分：验证安装是否成功

按下面清单检查一遍：
- [ ] Obsidian 安装完成并能正常打开
- [ ] Vault 创建完成，能看到主界面
- [ ] Chrome 浏览器右上角出现 Obsidian 图标
- [ ] 扩展登录成功，能识别本地 vault
- [ ] 找一个网页测试收录，能在 Obsidian 中看到新笔记
- [ ] 笔记里网页内容、图片、标题都正常显示

全部打勾就说明搭建成功，可以开始用了。

## 常见问题

**Q：扩展安装后没有反应？**
A：检查浏览器是否允许扩展访问文件网址，在 Chrome 扩展管理页面找到 Obsidian Web Clipper，勾选「允许访问文件网址」。

**Q：收录时提示找不到 vault？**
A：确保 Obsidian 桌面端已经打开并加载了目标 vault，扩展依赖本地 Obsidian 客户端进行通信。

**Q：手机能用扩展吗？**
A：iOS 版 Obsidian 支持 Share Sheet 功能，可以在 Safari 分享时直接保存到 Obsidian。安卓需要用其他方案。

**Q：vault 文件夹能移动吗？**
A：可以，但移动后需要在 Obsidian 中重新打开该文件夹作为 vault。

**Q：换电脑了怎么办？**
A：把 vault 文件夹整个复制到新电脑，用「Open folder as vault」打开即可，所有笔记、设置、插件都保留。

# 第五部分：Obsidian + WorkBuddy 第二大脑体系（进阶）

> 完整方法论见 `references/second-brain-methodology.md`（本文由飞书文档公开版整理）。

装好 Obsidian 只是有了仓库；**第二大脑体系**才让仓库变成"AI 能读懂的长期记忆"。核心分工：

```
人        → 负责判断和决策
Obsidian  → 负责长期沉淀和结构化（本地 markdown）
WorkBuddy → 负责读取、整理、提炼和执行
```

## 5.1 8+4 层目录结构

```
00_首页.md          ← 作战室入口（风险看板 + 快速导航）
01_系统层/          ← 给 AI 看的底层规则（启动协议/业务全景/协作规则）
02_收集箱/          ← 所有待处理资料的唯一入口
03_项目层/          ← 按项目分文件夹
04_知识资产/        ← 提炼后的知识卡片（不堆原文）
05_技术成果库/      ← Agent / 脚本 / 工作流
06_组织与人/        ← 团队网络 + 外部关系
07_过程记录/        ← 日报 / 周报 / 月报 / 会议纪要
08_归档/            ← 已结束、仅需追溯的内容
20_生活/  30_爱好/  40_投资/   ← 全维度
```

设计原则：**收集箱必须清空；知识资产要提炼；敏感数据绝不入库。**

## 5.2 核心机制：让 AI 每次都"懂你"（01_系统层 三件套）

1. **WorkBuddy启动协议.md** —— 除非用户说"这次不用第二大脑"，否则 AI 先读本 vault 再干活：先读系统层 → 读相关项目页/知识资产 → 再处理任务
2. **业务全景.md** —— 写给 AI 看的背景：角色、KPI 口径、数据源位置、协作关系。**越具体越好**，别写成公司介绍
3. **协作规则.md** —— 人机分工契约：入口唯一、AI 先判断、确认机制（删除/外发/关键决策先问）、可追溯（卡片必须带来源）

## 5.3 日常运转节奏

| 时机 | 动作 |
|------|------|
| 随时 | 资料/链接/截图丢进 `02_收集箱` |
| 每天 | 对 WorkBuddy 说"帮我整理今天的收集箱"，下班前确认清空 |
| 每周 | 沉淀 1-3 条知识资产，刷新 `00_首页.md` 风险看板 |
| 每月 | 清理项目层、归档旧资料到 `08_归档/` |

## 5.4 飞书文档批量归档（196 篇 → 8 张卡片）

对 WorkBuddy 说：

> "扫描我飞书云文档中近半年修改或创建的文档，排除 Base/多维表格，只处理 docx/sheet/slides 类型。按八层结构分类，生成一份扫描总览。"

要点：① 排除 Base/多维表格 ② 每篇带 obj_token 可回溯 ③ 同主题合并提炼成一张卡片（不超过一屏）④ 每张卡片底部必须有 `## 来源 / 原文`。

## 5.5 五个坑

1. 别把原文全搬进 Obsidian——只存提炼后的长期价值
2. 分类别太细——8 个一级目录够用，拿不准先扔收集箱（入口唯一，分类延迟）
3. 系统层文件别写抽象——写给 AI 看，写口径、位置、关系
4. 扫描飞书要排除 Base——否则正文提取失败还占空间
5. 知识卡片必须写来源——否则几个月后找不到原文

- vault：`D:\obsidian\第二大脑`，8+4 层结构 + 系统层三件套 + 首页作战室 + 模板 + 首批知识卡片已就绪
- Obsidian 已配置：新笔记默认落 `02_收集箱/`、附件存 `99_附件/`、日记模板在 `99_模板/`
