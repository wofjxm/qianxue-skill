# 深度视频动作迁移提示词（Depth Map 视频）

来源（飞书）：https://ccnope4jr4h4.feishu.cn/wiki/PPSjw1MmpisSnnkcUinc3GmsnFd

## 提示词原文（可直接使用）
```
请分析我提供的参考视频，并将其转换为黑白深度视频（Depth Map）
要求：
1. 精确分析视频中的空间层级关系，包括：
   - 人物与镜头之间的距离
   - 人物身体各部位的前后关系
   - 前景、中景、背景之间的深度变化
   - 镜头移动产生的空间变化
2. 输出黑白深度图视频：
   - 白色代表距离镜头较近的区域
   - 黑色代表距离镜头较远的区域
   - 灰色表示中间距离
   - 保持连续自然的深度过渡，不要出现断层
3. 保留原始视频全部信息：
   - 保持原始分辨率
   - 保持原始帧率
   - 保持原始视频时长
   - 保持原始镜头运动轨迹
   - 保持人物动作节奏和运动速度
4. 确保每一帧之间的深度信息稳定：
   - 避免闪烁
   - 避免人物边缘抖动
   - 避免身体轮廓与背景粘连
   - 确保手部、脚部、头发等细节区域具有准确深度
5. 输出一段连续稳定的黑白 Depth Map 视频，用于后续 AI 动作迁移和视频生成。
不要添加任何艺术效果，不要改变原视频内容，只生成准确的空间深度信息。
```

## 在 WorkBuddy 中的使用方式
把参考视频提供给 WorkBuddy，并发送上述提示词，即可得到可用于动作迁移的深度视频。
