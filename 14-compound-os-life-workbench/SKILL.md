# COMPOUND.OS 人生工作台（个人长期复利操作系统）

来源（飞书）：https://ccnope4jr4h4.feishu.cn/wiki/SwswwwtaOiSDC3kXLCGchLRZnru

## 核心思路
不要只让 AI“做一个工作台”。真正决定成品质量的是七件事：
1. 产品定位：它解决什么问题。
2. 信息结构：页面分成哪些独立板块。
3. 数据规则：什么能增加、多久能增加、什么时候归零。
4. 视觉语言：颜色、字体、留白、层级和质感。
5. 视觉隐喻：抽象目标怎样变成一眼能懂的画面。
6. 动效逻辑：动效为什么出现，而不只是“让它动起来”。
7. 验收标准：什么状态才算真的完成。

COMPOUND.OS 的定位不是普通待办清单，而是“个人长期复利操作系统”，把五种完全不同的事情分开管理：AI 能力资讯、长期主线、今日任务、身体账户、重要关系。

## 一、准备环境
适合使用 Codex、Claude Code 或其他能够直接修改项目文件并运行命令的 AI 编程工具。

技术路线：
- 页面：React + TypeScript
- 桌面渲染：Vite
- 本地软件外壳：Python + PyWebView
- Windows 打包：PyInstaller

## 在 WorkBuddy 中的使用方式
可参照上述七条原则与技术路线，让 WorkBuddy 帮你从零搭建一个本地人生管理桌面应用；把本项目作为参考范式，先明确产品定位与信息结构，再进入编码。
